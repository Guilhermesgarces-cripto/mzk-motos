## 🏍️ Site MZK Motos (`index.html`)

Landing page cinematográfica para concessionária de motos em São Paulo.

### Funcionalidades:
- 🎬 **Hero Section** com animações cinematográficas (moto flutuante)
- 📰 **Ticker animado** com notícias
- 🏍️ **Catálogo de motos** com cards interativos e modal de detalhes
- 🖼️ **Galeria de imagens** com editor integrado (zoom, rotação, espelho)
- 📍 **Seções**: Estoque, Serviços, Sobre, Localização (Google Maps)
- 📱 **WhatsApp** flutuante para contato direto
- 🔐 **God Mode (CMS oculto)**: Atalho secreto `357` ativa painel admin
- ✏️ **Painel Admin**: Gerenciamento de estoque, destaques e informações em tempo real

---

## 📊 CRM MZK Motos (`crm.html`)

Dashboard CRM completo para gestão comercial de leads de motos.

### Funcionalidades:
- 📋 **Kanban Board** com drag & drop (Lead → Atendimento → Proposta → Ganho → Perdido)
- 👥 **Multi-usuário** com sistema de login (vendedores + gerente)
- 📊 **Painel Gerencial** exclusivo com KPIs, ranking, funil de vendas
- 🤖 **Bot MZK** assistente com quick buttons
- ⚡ **Automações** por etapa do funil
- ⏱️ **SLA Timer** com alertas visuais
- 🌡️ **Filtros** por temperatura (Quente/Morno/Frio)
- 📤 **Exportação** WhatsApp / CSV
- 💾 **Persistência** com localStorage
